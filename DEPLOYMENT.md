# Deployment checklist

1. Create a public GitHub repository named `pc-procurement-dashboard`.
2. Initialize it with a README so the `main` branch exists.
3. Upload the dashboard contents to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select `main` and `/(root)`, then Save.
7. Confirm `index.html` is in the repository root and the Pages deployment succeeds.
